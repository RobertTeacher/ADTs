Big O Reference — Unit 19

Use Big O to describe growth as the input size increases. It is not an exact running time.

Important: complexity depends on the implementation. For example, an optimised bubble sort with an early-exit flag can have best-case O(n), while a fixed two-loop version remains O(n²) even on already sorted data. For trees, use h for tree height when discussing recursive stack space.
